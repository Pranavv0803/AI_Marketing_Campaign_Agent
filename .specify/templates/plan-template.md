## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

- [ ] **1. Hard Rules in Code**: Deterministic limits (lengths, hashtags, banned words) are validated in code, not delegated to LLM.
- [ ] **2. One Prompt per Step**: Generation pipeline steps are split into separate, single-purpose, independently testable prompts.
- [ ] **3. Runtime Brand Content**: Brand names, banned words, personas, and limits are externalized in runtime config/data.
- [ ] **4. Synthetic Data Only**: All datasets, samples, and demo assets are 100% synthetic (zero real/PII data).
- [ ] **5. Strict Secret Isolation**: API keys reside in git-ignored `.env`; `.env.example` contains only placeholders.
- [ ] **6. Plain, Inspectable Code**: Simple functions only; no LangChain, LangGraph, or agent framework bloat.
- [ ] **7. Demo-First Resilience**: Offline mock mode and pre-cached fallback campaign are planned and operational.
- [ ] **8. Exhaustive Rule Testing**: Unit tests cover boundary values, Unicode/emojis, and banned word variations.
- [ ] **9. Continuous Shippability**: Work is broken into small, green, independently shippable commits with core flow prioritized.
- [ ] **10. Honest Outputs**: Validation failures are surfaced directly with exact failure reasons (no silent hiding).
